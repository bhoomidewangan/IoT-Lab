# Experiment 9: Methane Alarm MQ2 Demo

Click MQ2 and increase ppm to change sensor response. MQ2 is NOT MQ4 and output is NOT calibrated methane concentration. Do not use as a safety-certified gas alarm.

Open Wokwi, choose Arduino Uno, paste `diagram.json` and `sketch.ino`, and add libraries from `libraries.txt` when present.
