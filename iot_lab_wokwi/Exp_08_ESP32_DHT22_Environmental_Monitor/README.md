# Experiment 8: ESP32 DHT22 Environmental Monitor

Wokwi-compatible PARTIAL simulation: ESP32 + DHT22 readings only. SX1278 LoRa radio/RF communication is NOT modeled here. Real hardware requires the two SX1278 modules and the separate transmitter/receiver code in `real_hardware/`.

Open Wokwi, choose ESP32, paste `diagram.json` and `sketch.ino`, and add libraries from `libraries.txt` when present.
